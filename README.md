## Wacker Kart

A 2D, Chicago-themed racing game prototype.

## Current Prototype

The repo currently contains a toy driving loop:
- blank screen canvas
- one controllable car
- arrow-key driving

Controls:
- `ArrowUp`: accelerate
- `ArrowDown`: brake / reverse
- `ArrowLeft`: steer left
- `ArrowRight`: steer right

## Run It

Open [index.html](./index.html) in a browser.

If your browser blocks local file input behavior, serve the folder with a simple static server instead.
